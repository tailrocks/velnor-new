# parity corpus

Intent: refactor-parity goldens (plan text, plan JSON, matrix JSON,
task report, expected set, generated workflow, jactionlint config) plus
`generate-tree.sha256`, the SHA-256 of every file `generate` writes, so a
change to any generated byte for these non-`[upgrades]` repositories shows up
as a deliberate golden refresh naming the changed files.
Each case holds `input/` (repo fixture) plus `expected/` (goldens).
The comparator normalizes repo path, run key, and generator SHA.

Cases: minimal-cargo, multi-crate (sharded), ignored-stack,
malformed, malformed-ignored.
