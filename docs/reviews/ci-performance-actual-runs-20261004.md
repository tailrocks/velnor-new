Jackin’s sibling `Rust / jackin-core` job `111202291450` saved the current-key entry at 12:27:25Z: 94,423,852 B uploaded at 70.5 MB/s (cache ID 8454323543). The core job ended at 12:27:30Z; the main `jackin` job ended at 12:39:21Z after its 172 s post-save step. Later, `Rust / jackin` exported 2,644 actions / 12,249 objects and showed 14.0 GiB in its local store, but same-key reservation failed. The later local candidate was not uploaded. The candidate contents’ useful delta was not independently verified. This is a measured same-key writer loss; no restore-path/version root cause was audited for Jackin.

The generator’s attempt-1 cache entry ID 8465890731 used primary key `linux-x64-mbx-velnor-mbx-1.21.1-dir-rust-39d372ba6fa2-9a249e9ab99a019ab7ba0e6f835dee406827db20`, size 70,254,045 B. Attempt 2’s Plan and Rust jobs reported `No mbx cache found`; saves collided with the existing key. Independent source audit verifies the cache-version inputs and establishes a source-backed causal inference for this miss:

- Exact source is commit `9a249e9ab99a019ab7ba0e6f835dee406827db20`, tree `27978528b42869f679eba58fc52577f81bbe39b1`, workflow blob `c73ae521905a29b75784ab3c89c4a95ef914dbef` (raw SHA-256 `879a2abc9626f3b3b5d45bd26f8b09b21fef0adc226b4f32e106cdfde9049160`). The workflow bytes are preserved at `/Users/donbeave/.codex-chainargos2/recovery-evidence/performance-ci-20261004/source/ci-9a249e9ab99a019ab7ba0e6f835dee406827db20.yml`.
- Pinned `jdx/mr-boxington-action@1687e54eb349cadf61fa38b5813a77875489e8e6` restores `[cacheDir/github-actions-cache-v1]` (`src/index.ts:349–359, 443–444`). The generated external saver stores `${{ runner.temp }}/mbx-single-bundle` (`ci.yml:364–369`).
- Pinned `actions/cache@55cc8345863c7cc4c66a329aec7e433d2d1c52a9` bundles toolkit 6.1.0. Its cache-version code hashes the ordered path vector (plus compression method, cross-OS flag where applicable, and salt); restore and save therefore calculate different cache-version values for these distinct paths. Same textual key does not repair that mismatch. Compression identity also needs to match, but path mismatch alone is sufficient.

The distinct path vectors produce distinct cache-version inputs in the pinned implementation. The source mismatch remains a source-backed explanation for the 9a miss, but the original audit did not capture and compare the version requested by attempt-2 restore with the stored entry's version.
