## Confirmed architectural defects

1. **C01/C02:** Separate Mise absolute restore and tilde save payloads; isolated Rustup outside the saved tool closure. Actual logs show repeated installer/component downloads and existing-key save reservation failures. Fixture Plan saved a visible Mise key, then its downstream shared Rust job restored the same visible key as a miss and spent 13.6 seconds reinstalling five tools.
2. **C03/C05:** Sibling validation writers share immutable MBX revision keys and lose useful later state. Termpane fuzz wins while three siblings fail reservation. Fixture app-a publishes a small snapshot; harness restores 13 workspace files/6.9 MiB, produces more work, then skips save on exact hit. Parallax server exact-hit export skips despite approximately 24.3 GiB local cache state; xtask collides. These observations do not prove safe useful-delta semantics; T03/T05/T17 remain required.
3. **C04:** MBX consumers install through Mise and the transport action; exact executable ownership and compiler probe alignment require the upstream fix and qualification. Some Rust consumers instead configure `compile_driver = "cargo"` with no MBX transport. Termrock, terminal-components-claude and tui-snap restore ambient Cargo homes while task execution uses isolated homes, causing real source misses/downloads despite archive hits.
4. **C06:** Source archives restore successfully in MBX consumers, but saves still attempt unchanged-key reservation. Selected closure and exact/prefix useful-delta behavior remain unqualified.
5. **C07/T25:** Fully covered work is skipped at task steps after job allocation/setup. Ten skill and seven distribution consumers have empty application matrices, yet Plan installs Rust and six components for a prebuilt helper. Repository-skills actual Rust install takes approximately 12.4 seconds; tools-only sampled setup spans about 12–24 seconds. No irrelevant MBX archives were present in these tools-only cases.
6. **Section 6/T16:** PR plan head identifies feature head while checkout executes a different synthetic merge candidate. Actual plan artifacts and checkout logs independently show this in tools-only, IaC, fixture, and Rust consumers. Baseline-unavailable plans execute work, so this audit does not claim an observed false-negative; exact candidate/proof binding is nevertheless wrong.
7. **C08/C09:** Setup, imports, linking/preparation, test execution and exports must be measured separately. Tablerock FFI spends 697 seconds in MBX post-export, then loses reservation to a sibling. Its Clippy reports zero hits/misses but 621 not-looked-up units and four `cc-missing-output` bypasses. Termrock and terminal-components-claude have real Nextest execution floors of 203.753 and 169.181 seconds, respectively; blanket sub-two-minute claims would be unsupported.
