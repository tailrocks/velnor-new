# Product version preparation for v0.1.13

This is source preparation on `native-preview`, following verified feature
checkpoint `23270f3ccb0513923835baa600df3ba2b46b37fa`. It does not establish an
official release, consumer deployment, or successful Homebrew upgrade.

The root workspace version, exact local path requirements, local lock entries,
and generator release asset catalog now select 0.1.13. The independently versioned
runner workspace, external tool pins, static consumer release manifest, captured
v0.1.12 attestation evidence, and historical qualification records are preserved.
The obsolete unregistered standalone generator-release snapshot module was removed;
active product-release workflows retain their shared snapshot assertions.

The release-tag preflight verified that both `v0.1.13` tag and release endpoints
returned authenticated, well-formed 404 responses. No occupied tag was reused.
Workflows were regenerated by the new CLI; the separate preview tree matched the
repository output byte for byte. Release snapshots were copied from those generated
workflow/action bodies, without their generator marker. The four parity cases passed both capture and comparison. All five OpenTofu
cases matched, including the identical dogfood tree. Final repository gates and
hosted checks remain mandatory at the release head.

Publication requires merging the reviewed source, successful exact-main CI, and
the canonical product-release workflow. The existing `generator-release` human
review environment remains in place. Hosted three-target qualification, signatures,
immutable publication, and installation-manifest verification remain release gates.
Unattended tap promotion additionally requires the separately qualified completion
App and repository/credential settings; local tests do not satisfy those live gates.
